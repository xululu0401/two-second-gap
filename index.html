隔两秒够不够

跟在一辆车后面，它突然急刹，你来得及吗？填车速、隔几秒（或几米）、你多久反应过来、刹车多猛，按匀减速算一遍：会不会撞上，要隔几秒才刹得住。

这一段路

刹车多猛 = 每秒掉多少速度（m/s²），这是你自己的假设：干路面用力踩一般按 6–8 填，下雨、轮胎旧、车重就往低填。反应时间 = 看到刹车灯到脚踩下去，分神时会更长。本页不提供真实车型和路面数据。

    路面上：两辆车各自在哪停下

    你前车 / 停着的东西撞上的位置

    两车之间还剩几米（从前车刹车那一刻算）

    两车间距你要留的0 = 撞上

    换个车速、换个秒数（前车同速，其余照你填的；点一格 = 代回那个车速和秒数）

    撞 N = 撞上那一下比前车快 N km/h；剩/贴 = 停下后最近还剩几米（贴 = 不够你要留的）。「前面停着东西」时每格都是停着的东西。

      拿走结果

      按匀减速和你填的数算，没算刹车起效的那一下延迟、ABS、坡道、弯道、车长和后车；所有数是你自己的假设，不是安全标准，算出来刹得住不代表现实里一定刹得住。默认数据为虚构示例。填的内容只存在本机浏览器。
